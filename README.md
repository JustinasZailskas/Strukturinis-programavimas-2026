# Struktūrinis programavimas 2026

Šioje repozitorijoje pateikiamas **trečiosios praktinės užduoties duomenų failas**.

## Duomenų failo struktūra

- **Pirmoje eilutėje** nurodomas bendras įrašų skaičius.
- **Kitose eilutėse** pateikiami duomenų įrašai, kurių laukai atskiriami kabliataškiu (`;`).

Kiekvieno įrašo formatas:

`kategorija;pavadinimas;kaina;kiekis`

## Duomenų failo pavyzdys

```text
3
Dviraciai;KROSS Level 4.0;950.00;2
Dalys;Shimano CN-HG53 grandine;20.00;12
Aksesuarai;KROSS Capitalo salmas;45.00;10
```

**Pastaba:** Kaina nurodoma eurais, naudojant tašką kaip dešimtainį skirtuką.
